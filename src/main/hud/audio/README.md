# HUD audio outputs

`launch.ogg` and `lock_confirm.ogg` are purpose-built deterministic syntheses
designed for Minecraft's short, dry feedback style. `missile_warning.ogg` and
`missile_critical.ogg` are edited from external CC0 1.0 assets. None of the
four files contains material extracted from Minecraft, *Ace Combat 7* or
another commercial game.

The complete synthesis recipe, external-source verification and encoding
pipeline live in `tools/build-hud-audio.ps1`. Authors, source URLs, original
download hashes and the CC0 license for the warning clips are documented in
`../third-party/README.md`.
